# 🍱 Lunch Stamp（お昼ごはんスタンプラリー）

ランチのお店選びに迷う都内オフィスワーカー向けに、
店舗一覧とスタンプラリー機能を提供し、
楽しみながら新しいお店を開拓できるアプリです。

※ 現在は「人形町エリア」に特化して開発しています。

---

## 📝 Overview

Lunch Stampは、日々のランチ選びを「スタンプラリー」として楽しめるWebアプリです。
訪問した店舗を記録し、コンプリート率を可視化することで、
ゲーム感覚で継続的にランチ開拓ができる仕組みを提供します。

---

## 🎯 Target Users

* 20〜40代の都内オフィスワーカー
* ランチのお店選びに毎回悩んでいる方
* 新しいお店を開拓したいがきっかけがない方
* 楽しみながらランチを充実させたい方

---

## 💡 Problem & Solution

### ■ Problem

* 同じ店ばかり行ってしまい、新しいお店を開拓できない
* ランチ選びがマンネリ化している

### ■ Solution

* 人形町エリアの店舗を一覧化
* 訪問した店舗にスタンプを付与
* コンプリート率を可視化（％ + 進捗バー）

👉 ゲーム感覚でランチ開拓を継続できる体験を提供

---

## ⚙️ Features

### ■ 認証機能

* ユーザー登録
* ログイン / ログアウト

### ■ 店舗機能

* 店舗一覧表示（ログイン後トップ）
* ジャンル検索 / 予算検索
* コンプリート率表示（進捗バー）

---

### ■ 店舗詳細

* 店名 / エリア / ジャンル / 予算表示
* 訪問状態の表示

未訪問：

* 「訪問を記録する」ボタン表示

訪問済み：

* 訪問日表示
* 訪問記録詳細へのリンク

---

### ■ スタンプ（訪問記録）機能

* 訪問記録の作成（restaurant_id, visited_at）
* 訪問日の編集
* スタンプ削除（解除）

※ 1ユーザー × 1店舗 = 1スタンプ

---

### ■ マイページ

* 表示名 / メールアドレス表示
* 行った店数 / 総店舗数
* コンプリート率（％ + 進捗バー）
* 最近の訪問履歴一覧

---

### ■ プロフィール機能

* 表示名編集
* メールアドレス編集
* パスワード変更

---

## 🎯 Motivation（なぜ作ったか）

社会人になり、毎日のランチで同じ店ばかりに行ってしまうことに気付きました。
「街には多くのお店があるのに開拓できていない」という課題を感じ、
ランチを“義務”ではなく“楽しみ”に変えられる仕組みを作りたいと考えました。

そこで、スタンプラリー形式でゲーム感覚にできるアプリを企画しました。
日常の小さな行動を少し楽しくするサービスを目指しています。
